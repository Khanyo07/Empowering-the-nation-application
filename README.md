# Empowering the Nation — Mobile Application

Mobile web application for **Empowering the Nation** (XHAW5112). Same content and fee rules as the website, laid out to the Task 1 mobile wireframes: navy app bar, fixed bottom navigation (Home, Courses, Fees, Contact), menu drawer, accordions and a two-step fee calculator.
